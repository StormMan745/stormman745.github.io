# Воспоминания PetCare

Месяц воспоминания необязателен: в форме «Новое воспоминание» поле можно оставить пустым. Подборка хранится с `month: null` и отображается как «Воспоминание без даты»; в видео календарная подпись не добавляется. Подборки из фотобиблиотеки также создаются без обязательной даты. Дата первого еженедельного напоминания показывается и проверяется только при включённых напоминаниях. Для самих фотографий дату тоже можно очистить: снимки без даты остаются в порядке кадров после датированных, а в библиотеке есть фильтр «Без даты».

## Фотобиблиотека

В начале раздела находится отдельная библиотека фотографий выбранного питомца. «Добавить фото» принимает до 20 снимков за одну загрузку, до 20 МБ каждый. Снимки оптимизируются до 1800 пикселей по длинной стороне и сохраняются в JPEG. Оригиналы пользовательских файлов не заменяются на устройстве; библиотека хранит оптимизированные копии. Дата по умолчанию берётся из даты изменения файла; её можно исправить в просмотре. EXIF-дата не извлекается автоматически.

Фотографии можно открывать, скачивать, удалять и фильтровать по месяцу. Сетка показывает по 24 снимка с кнопкой «Показать ещё». Выберите от 2 до 12 снимков и нажмите «Создать фильм из выбранных»: ниже появится обычная подборка с датами, музыкой и форматом. Для неё сохраняются отдельные копии фото, поэтому удаление из библиотеки не затрагивает подборки. Затем нажмите «Создать видео» в подборке. Ранее созданные фильмы продолжают работать; библиотека заполняется через собственную кнопку загрузки.

Метаданные хранятся в существующем снимке аккаунта: элементы `storyProjects` с `kind: 'photo-library'`, `petId` и массивом `photos` с независимыми ID. Они не отображаются как фильмы. Используется прежний приватный bucket `petcare-stories`, пути `user_id/album_id/photo_id.jpg`, очередь файлов и IndexedDB. Это сохраняет существующие правила доступа, общий экспорт, очистку и удаление питомца без изменения схемы сервера. Черновые Data URL не записываются в профиль. Смена аккаунта и питомца очищает выбор и просмотр. Логика — `photo-library.js`, проверка — `npm --prefix tools run test:photo-library`.

В разделе «Воспоминания» владелец добавляет от 2 до 12 фотографий с телефона, камеры или компьютера. Даты определяют порядок кадров. Два снимка дают видео на 10 секунд, четыре — на 20 секунд, двенадцать — на минуту. Можно выбрать вертикальный (720×1280) или горизонтальный (1280×720) формат, одну из двух оригинальных спокойных мелодий либо видео без музыки. Пустые места в редакторе добавляются постепенно; фотографии для кодирования уменьшаются до 1280 пикселей по длинной стороне, чтобы ограничить расход памяти на телефонах.

Изображения плавно приближаются и сменяют друг друга с растворением. Подложка с размытием позволяет сохранить питомца в кадре при разном соотношении сторон исходных фотографий. Музыка синтезируется на устройстве и входит в готовый файл; микрофон и внешние музыкальные сервисы не используются. Видео не запускается со звуком автоматически.

## Создание и сохранение

- Основной экспорт: MP4, H.264 + AAC, 30 кадров/секунду через WebCodecs и Mediabunny.
- Для браузеров без нужных WebCodecs используется MediaRecorder: MP4, если поддерживается, иначе WebM. Расширение и MIME соответствуют реальному контейнеру.
- Прерванное создание не заменяет готовое видео. Для резервного режима нужно оставить приложение открытым: уход в фон останавливает создание с объяснением.
- Сохранение использует приватное хранилище `petcare-stories`, уже допускающее MP4, WebM и JPEG до 25 МБ. Новых публичных политик или ключей нет.
- Файлы сначала сохраняются в очередь текущего аккаунта. Если отправка не удалась, видео доступно локально, отображается ожидание отправки, прежний подтверждённый файл сохраняется. Кнопка повторной отправки не кодирует фильм заново. После успешной отправки обновляется статус; прежние файлы удаляются после сохранения профиля.
- Готовый файл можно скачать или передать через системное меню «Поделиться». Возможность сохранения в Фото/Галерею зависит от доступных действий ОС и поддержки формата. Установленные нативные оболочки используют существующий `PetCareNative.shareFile`.
- При выходе из аккаунта создание отменяется и очищаются временные ссылки и кэш в памяти. Файлы IndexedDB изолированы по аккаунтам существующим слоем офлайн-хранения.
- Ранее сохранённые фотоколлажи остаются в раскрывающемся блоке. Напоминания о еженедельной съёмке продолжают работать.

## Сборка и проверка

`npm ci --prefix tools --ignore-scripts`

`npm run --prefix tools build:memories`

`npm run --prefix tools build:app`

`npm run --prefix tools test:memories`

Видеокодек загружается только при создании фильма. Сборщик `tools/build-memories.cjs` создаёт `memories.bundle.js`; service worker сохраняет его для повторной работы без сети. Проверка создаёт настоящие MP4 в Chrome, декодирует аудиодорожку и проверяет ненулевую громкость, размеры и длительность видео, загрузку 2/4/12 фото, минутный фильм, уменьшение больших изображений, хронологию, отмену, очередь при сбое отправки, скачивание и изоляцию питомцев/аккаунтов. Отдельно проверяются экспорт через MediaRecorder со звуком и отмена при выходе из аккаунта. Сервер в проверке подменён; проверка настоящих iPhone и Android отдельно не автоматизирована.
