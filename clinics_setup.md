# Встроенный справочник мест для питомцев

Карта, поиск адресов и организаций, телефоны, графики, статусы работы и маршруты отображаются встроенным виджетом **Яндекс Карт**. Клиент не обращается к Photon, Nominatim, OpenStreetMap или другим справочникам. Для виджета не нужен API-ключ. [Официальное описание бесплатного виджета](https://yandex.ru/dev/maps/mapstools/).

## Поиск

Посетитель выбирает клиники, круглосуточные стационары, пункты бесплатной вакцинации, площадки для выгула, приюты или зоогостиницы. После ввода адреса приложение передаёт Яндексу запрос с названием выбранной категории. Для клиник и зоогостиниц флажок «Искать открытые сейчас» добавляет это условие в запрос. Нажатие на название или метку открывает встроенную карточку с доступными сведениями и маршрутом. Приложение не копирует ответы справочника и не подменяет их собственными данными.

Поиск Яндекса по ключевым словам может показывать неточные результаты. Для каждой категории есть прямая ссылка на соответствующий слой [городской карты mos.ru](https://www.mos.ru/pgu/ru/app/dvm/mypets/?page=info&map_layer=0); для бесплатной вакцинации дополнительно открывается [официальный график пунктов](https://www.mos.ru/moskomvet/function/punkti_vakcinacii/).

Результаты и сведения об организациях обслуживает Яндекс; полнота и актуальность зависят от него. Перед поездкой следует позвонить. В бесплатном виджете могут показываться объявления провайдера, его логотип и атрибуция сохраняются.

## Геопозиция и аккаунт

При неопределённом разрешении геолокация запрашивается кнопкой «Разрешить геопозицию». Если разрешение уже выдано, позиция определяется при первом открытии раздела. Координаты задают область поиска Яндекс Карт. Переключатель над виджетом позволяет посмотреть клиники рядом или своё местоположение. При отказе доступен поиск по адресу. Непрерывного слежения нет.

После выхода из аккаунта или смены пользователя очищаются адрес, координаты и выбранная категория, встроенная карта удаляется. При закрытии раздела виджет удаляется, чтобы остановить фоновую работу. Данные питомца в Яндекс не передаются.

## Локальный файл и публикация

`node tools/build-clinics.cjs` собирает классический `clinics.bundle.js` из `clinics.js`. В рабочем загрузчике нет ES-module imports, поэтому поиск доступен и по HTTPS, и при открытии локального `index.html`. Стандартная отправка HTML-формы всегда отменяется основным кодом, в том числе при ошибке загрузки виджета. Поиск не перезагружает приложение и не вызывает выход из аккаунта.

Service Worker кэширует только файлы приложения. Внешний виджет и его данные он не перехватывает. В CSP разрешено встраивание только Яндекс Карт. Старый API `petcare-clinics` возвращает 410 с предложением обновить клиент; старые таблицы ограничителя не используются. Ключи 2ГИС и другие API-ключи для этого варианта не требуются.

Проверены: встроенная карточка реальной клиники с телефоном и графиком, поиск по адресу в другом городе, локальный файл и HTTPS, кнопка и Enter, задержка и отказ загрузки кода, геопозиция с разными разрешениями, очистка состояния аккаунта и адаптивность интерфейса.
