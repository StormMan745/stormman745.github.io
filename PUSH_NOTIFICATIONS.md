# Уведомления PetCare

В разделе «Напоминания» включите push и разрешите уведомления. На iPhone/iPad открывайте PetCare с главного экрана (iOS/iPadOS 16.4 и новее). Chrome/Edge на Android и компьютере могут получать push из браузера без установки.

В разделе показаны три независимых статуса: доставка по расписанию, разрешение устройства и пробное уведомление. Подключённая подписка не означает, что уведомление уже показано. После подключения нажмите «Проверить уведомления». На сайте это отправка через Supabase и службу Apple/Google/Mozilla/Microsoft. Пробное сообщение ограничено одним запросом на устройство в минуту и доступно только владельцу подписки с действующей сессией. Ответ «принято push-службой» не подтверждает показ на устройстве.

После принятой отправки появятся кнопки «Уведомление пришло» и «Не пришло». Только подтверждение владельца переводит третий статус в «Получено — подтверждено вами» с датой и временем. Ответ «Не пришло» открывает подсказки для текущей платформы. Результат проверки хранится только локально, отдельно для каждого аккаунта, и не синхронизируется между устройствами. При отключении уведомлений, отзыве разрешения в браузере/мобильном приложении или потере подписки проверка сбрасывается. Ошибки отправки и ожидание не считаются получением. Ответы незавершённых проверок после смены аккаунта игнорируются.

В мобильной сборке пробное локальное уведомление планируется через 5 секунд; обновление обычного расписания не отменяет ожидающую проверку. При выходе и отключении удаляются также тестовые уведомления. Разрешение берётся из системного API Capacitor. На Windows пробное сообщение отправляется через защищённый Electron IPC; ошибки показа отображаются в третьем статусе. Electron сообщает поддержку уведомлений, но не даёт достоверной проверки пользовательского разрешения Windows: интерфейс предлагает проверить настройки, не утверждая, что разрешение получено. Принятый системой показ тоже требует подтверждения владельцем. Проверки API платформ автоматизированы с подменой показа; реальные звук, Focus и доставка на физических устройствах требуют ручной проверки.

Создайте напоминание с будущей датой и временем. Оно должно синхронизироваться с аккаунтом. Сервер проверяет расписание каждую минуту, учитывает часовой пояс устройства, повторения и выполненные приёмы. Короткая задержка планировщика допускается; окно повторной отправки — до 15 минут. Повторные запуски защищены атомарной арендой отправки. Недоступному телефону служба может доставить принятое напоминание позже (TTL — один час).

Устаревшие подписки удаляются после ответа службы 404/410. Включите push заново на таком устройстве. При выходе из аккаунта его подписка на данном устройстве отключается. Данные другого аккаунта и его уведомления через тест недоступны.

Ежедневные дела: в блоке «Сегодня» включите «Заранее напоминать о делах», выберите 5/10/15/30 минут и подключите push на устройстве. Существующие аккаунты автоматически не включаются. При нескольких выполнениях используется отдельное время каждого. Выполненные отметки и дела с выключенным флажком в редакторе пропускаются. Общий выключатель сохраняется для выбранного питомца и не отключает обычные напоминания. После офлайн-изменений сервер использует новую настройку после синхронизации. Предварительное сообщение не отправляется после наступления времени дела; TTL ограничен оставшимся временем. Уже принятое службой уведомление нельзя отозвать.

Звук не подавляется (`silent: false`), запрашивается вибрация. Сайт не может отменить беззвучный режим, Focus/«Не беспокоить», запрет уведомлений или ограничения энергосбережения. Звук и показ проверяются на настоящем телефоне; программные тесты используют подменённую службу доставки.

Для APK Android версия 1.0.1 добавляет отдельный звуковой канал «Напоминания PetCare» с системной мелодией и вибрацией. В него направлены обычные и ежедневные события и проверка. Идентификаторы событий не переиспользуются при сдвиге очереди, поэтому новое событие не заменяет старое видимое уведомление без нового звука. Кнопка «Настроить звук уведомлений» открывает настройки канала; режим телефона, громкость и выбранную мелодию контролирует владелец. Существующие настройки канала сохраняются. Установленный APK нужно обновить файлом новой сборки; публикация сайта его не обновляет.

Проверки: `npm --prefix tools run test:push`, `npm --prefix tools run test:security`, `npm --prefix tools run test:auth`, `npm --prefix tools run check:build`.
