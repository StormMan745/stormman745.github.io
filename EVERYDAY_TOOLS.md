# Небольшие инструменты на каждый день

Обновление 5 ноября 2026: дополнительные функции открываются отдельными экранами, без постоянных лент на главной. Общий поиск находится по кнопке на главной и в профиле. История самочувствия и месячные расходы свёрнуты; длинные списки загружаются порциями по 25 записей.

## Где находятся функции

- **Здоровье → Самочувствие:** аппетит, активность, настроение и необязательная заметка. Одна запись на питомца и дату; можно выбрать прошлый день, изменить или удалить запись. Оценки — наблюдения владельца, без автоматического диагноза.
- **Питомец → Расходы и корм → Расходы:** категории, сумма в рублях, дата и заметка. Итог выбранного месяца считается отдельно для каждого питомца; деньги хранятся целым числом копеек.
- **Питомец → Расходы и корм → Запас корма:** фактический остаток в килограммах, дата замера, расход в граммах за день и запас времени на покупку. Расчёт не меняет сохранённое количество каждый день: остаток вычисляется по календарным датам без зависимости от перехода на летнее время. После покупки или изменения порции владелец уточняет остаток. Это оценка, не назначение рациона и не автоматическое push-напоминание.
- **Питомец → QR для ошейника:** отдельно подтверждённые имя, фотография и один контакт — телефон, Telegram или email. Фото можно выбрать с устройства или взять из профиля. Готовая карточка скачивается в PNG для печати. Контакт можно обновить, сохранив QR; доступ можно отключить. Если локальная ссылка потеряна, доступен выпуск нового кода с отключением старого.
- **Поиск по записям:** названия и текстовые поля здоровья, документов, назначений, напоминаний, дневника и расходов. Область — выбранный питомец либо все питомцы текущего аккаунта. Поиск локальный; содержимое сканов и PDF не распознаётся. Без сети ищутся сохранённые на устройстве метаданные документов.
- **Чат:** явная просьба «напомни…» подготавливает черновик на устройстве. Распознаются ISO-дата, ДД.ММ.ГГГГ, сегодня, завтра, послезавтра, через N дней, время ЧЧ:ММ и ежедневный повтор. Неуказанные дата и время остаются пустыми. Владелец проверяет поля и нажимает «Подтвердить и сохранить». Повторное подтверждение не создаёт дубликат. Действие использует обычные напоминания и существующую push-доставку после синхронизации.

## Данные и доступ

`wellbeingEntries`, `expenses`, `foodStocks` хранятся в существующем снимке аккаунта, каждая запись имеет `id` и `petId`. Существующее слияние по ID сохраняет изменения с нескольких устройств. Работают IndexedDB, офлайн-перезагрузка, синхронизация и общий экспорт; удаление питомца удаляет эти записи. Ошибка локального сохранения откатывает изменённую запись. Редактор отвергает сохранение поверх изменённой версии.

QR использует отдельную таблицу `petcare_collar_cards`: исходные данные аккаунта туда не копируются. Все прямые клиентские права отозваны, RLS включён. Приватные действия Edge Function требуют действующей серверной сессии и владельца питомца. Публичное чтение требует случайного 256-битного токена; в таблице хранится только SHA-256. Токен находится во фрагменте ссылки и не попадает в HTTP-запрос страницы. Сервер ограничивает чтение существующей карточки до 120 запросов в минуту и 5000 в день. Квоты атомарны и доступны только серверной роли.

Публичный ответ отдаётся с `no-store`. Страница скрывает данные при потере подтверждения доступа, уходе в фон и не позднее минуты без успешной проверки. Отключение очищает опубликованные фото и контакт, удаление питомца или аккаунта удаляет карточку и её квоты. Уже скачанные посторонними копии отозвать невозможно. Для публикации, изменения и просмотра QR-карточки нужен интернет; дневник, расходы, корм и сохранённая история работают офлайн.

Генератор QR `qrcode-generator@2.0.4` поставляется локально с MIT-лицензией и загружается при скачивании. Фото, контакты и QR не отправляются сторонним генераторам. Файл собирается командой `npm run --prefix tools build:qr`. Контакт, расходы и корм автоматически не передаются GigaChat. Напоминание из явной просьбы создаётся локальным разбором текста без обращения к модели.

## Проверки

`npm run --prefix tools test:extras`: все шесть функций в Chrome с имитацией внешних API, офлайн-перезагрузка, независимость аккаунтов и питомцев, суммы в копейках, расчёт дат, XSS, отмена/подтверждение черновика, QR с фото/скачиванием/отзывом, отказ хранилища и ширины 320/390/1440. `tools/check-care-edge.cjs` проверяет авторизацию карточек, набор публичных полей, ограничения контактов/фото, квоты и отзыв. `tools/check-collar.sql` проверяет реальные права ролей, квоты и удаление в транзакции с откатом. PNG дополнительно проверен независимым QR-декодером. Проверки на физических iPhone и Android не выполнялись.

Кэш приложения: `petcare-shell-v47-everyday-tools`. Для обновления сборки: `npm run --prefix tools build:app`.
