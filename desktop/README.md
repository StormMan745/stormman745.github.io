# PetCare для Windows

Самостоятельное приложение на Electron с локальной копией интерфейса и SDK. Для запуска не нужны Node.js и отдельный браузер. Поддерживается Windows 10/11 x64.

## Запуск

В `desktop/releases` создаются два файла:

- `PetCare-1.0.0-Windows-Setup.exe` — установщик для текущего пользователя с выбором папки и ярлыками.
- `PetCare-1.0.0-Windows-Portable.exe` — переносная версия, запускается без установки.

Данные аккаунта загружаются после входа; вход, синхронизация, карта и ИИ требуют подключения к интернету. Временные файлы для просмотра очищаются при сбросе аккаунта и выходе, если их не удерживает внешняя программа. Сохранённые пользователем документы остаются в выбранной папке.

Закрытие основного окна сворачивает PetCare в область уведомлений рядом с часами. Чтобы полностью закрыть программу, нажмите правой кнопкой по значку PetCare и выберите «Выйти из приложения». Автоматический запуск вместе с Windows не включается.

## Возможности Windows

- Системный диалог сохранения документов и коллажей.
- Открытие оригиналов документов в установленном приложении Windows. Кнопка печати оригинала открывает этот просмотрщик и подсказывает использовать Ctrl+P.
- Медицинская карточка печатается через системный диалог из приложения; доступно сохранение в PDF через принтер Microsoft Print to PDF.
- Системные напоминания для ближайших 60 событий с заданным временем. Они работают, пока процесс PetCare запущен, в том числе после сворачивания в трей. Полный выход, выключенный компьютер и ограничения Windows останавливают доставку. После сна старые события более чем за 10 минут не воспроизводятся.
- Отдельные данные входа от браузера и мобильной версии; общая облачная учётная запись. При смене аккаунта ожидающие уведомления очищаются.

Геопозиция запрашивается по разрешению пользователя; её доступность зависит от Windows и провайдера Chromium. В разделе карты можно всегда указать город и адрес вручную.

## Сборка из исходников

Нужен Node.js 22.12 или новее. Команды из папки `desktop`:

```sh
npm ci
node node_modules/electron/install.js
npm run build
npm start
npm run dist
```

Исходный интерфейс берётся из корня проекта. Мост Windows находится в `src/desktop.js`, системные операции — в `main.cjs`, узкий интерфейс IPC — в `preload.cjs`. В программу копируются только необходимые файлы. Renderer работает с sandbox, contextIsolation и без Node.js; документы проверяются по содержимому, внешний контент не получает доступ к IPC.

`npm test` запускает настоящую среду Electron, проверяет загрузку, изоляцию, PDF-рендеринг, отклонение исполняемых файлов, планирование/сброс уведомлений и адаптивность. Тест использует существующий Playwright из `.tools/preview`; вход реального пользователя, физический принтер и доставка тостов Windows вручную не проверялись.

Сборки пока не имеют сертификата издателя и автоматических обновлений. Это версия для тестирования и демонстрации, не публикация в Microsoft Store.
