# Передача записей из клиник

Автоматическая передача приёмов и обследований из клиник отключена. Ранее сохранённые записи доступны в истории здоровья. Результаты обследований можно добавлять вручную в разделе «Документы и результаты обследований».

Старый адрес приёма данных возвращает HTTP 410. Клиники могут прекратить отправку на него.
