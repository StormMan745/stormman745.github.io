# Поиск мест по стране

В «Местах для питомцев» выбирается страна. Для России используется встроенный справочник Яндекс Карт; для остальных стран — публичный виджет Google Maps с поисковым запросом. Доступна отдельная ссылка на полный поиск Google Maps URLs (`api=1`), не требующая API-ключа.

Сохраняется только ISO-код выбранной страны в `mapCountry` аккаунта, через существующее офлайн-сохранение и синхронизацию. Адрес поиска и координаты не записываются в профиль. При выходе из аккаунта карта и координаты очищаются; поздний ответ геолокации игнорируется.

При поиске по адресу Google получает адрес и название выбранной страны. При поиске рядом используется реальная геопозиция устройства. Выбор страны сам по себе не меняет GPS-координаты. Названия категорий для Google передаются на английском, интерфейс карты запрашивается на русском. За пределами России категория вакцинации не обещает бесплатную услугу.

Яндекс показывает пользовательскую синюю метку вместе с местами. Публичный Google-виджет показывает найденные места; «Приблизить меня» отдельно открывает точку устройства, а «Места рядом» возвращает результаты. Легенда синей метки для Google скрыта. Контакты, график и маршруты доступны в полном Google Maps по ссылке; полнота справочника зависит от страны и сервиса.

Публичный виджет не заменяет документированный Maps Embed API: его поведение может измениться. Если он недоступен, остаётся ссылка на полный поиск. Для перехода на Maps Embed API потребуется отдельный ключ Google Cloud с ограничениями. Никакие ключи или платные API в этой реализации не добавляются.

Документация: https://developers.google.com/maps/documentation/urls/get-started ; https://support.google.com/maps/answer/7101463 ; https://developers.google.com/maps/documentation/embed/embedding-map .

Проверки: `node tools/check-offline-care.cjs --map-country`; добавить `--map-mobile` или `--map-mobile --iphone` для эмуляции мобильного устройства, `--real-map-country` — для загрузки настоящего Google-виджета. Сервисы авторизации в тестах подменены.
